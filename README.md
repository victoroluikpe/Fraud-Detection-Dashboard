# SHAP Fraud Detection Dashboard

This is a **Streamlit web application** for detecting fraudulent financial transactions using both **Machine Learning (Random Forest)** and **Deep Learning (LSTM)** models.  
It also provides **SHAP explanations** for model predictions, helping users understand feature contributions.

---

## 🚀 Features
- Upload financial transaction data for fraud detection.
- Predict fraud using:
  - **Random Forest (traditional ML model)**
  - **LSTM (deep learning model)**
- Explain model predictions with **interactive SHAP plots**.
- Support for ONNX and quantized models for lightweight deployment.
- Visualization of feature importance for transparency.
